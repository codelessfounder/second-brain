1. System messages - Use a combination of system and user messages for more accurate LLM outputs
2. Write clear instructions - Include details in your query to get more relevant answers. Use delimiters to clearly indicate distinct parts of the input. Specify the steps required to complete a task. Provide examples (few-shot prompting).
3. Provide reference text - Instruct the model to answer with citations from a reference text.
4. Split complex tasks into simpler subtasks.
5. Give the model time to "think" - Instruct the model to work out its own solution before rushing to a conclusion.
6. Use external tools - Use embeddings-based search to implement efficient knowledge retrieval. Use code execution to perform more accurate calculations or call external APIs.
7. Test changes systematically.
